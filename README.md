This repository preserves an older public edition and pinned examples. Current public docs live
in [HexintonDev/public-docs](https://github.com/HexintonDev/public-docs); internal architecture
and build guidance live in the separate `HexintonDev/docs` repository.

## Scope

This public repository contains usage and scripting documentation only. Internal architecture,
product designs, requirements, implementation plans, and private operational notes are not part of
this site.

## Evidence

The technical pages and samples are cross-checked against the ProcessEngine implementation and
automated test fixtures. Source repository URLs are intentionally omitted from this public site.
